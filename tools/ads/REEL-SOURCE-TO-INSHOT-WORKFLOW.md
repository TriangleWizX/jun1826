# Existing footage to Meta Reel: phone workflow

Use this when the source footage is already in Google Photos or on your YouTube channel and the finished edit will be made in InShot on your phone. This is a source-selection and editing handoff, not an automated connection to either library. You choose and review the actual footage.

## The production unit

Each Reel needs one audience, one question, one visible teaching point, one proof sequence, and one next step. A short and a long Reel may come from the same class recording only when they teach different points and use distinct edits. Facebook and Instagram get the same creative and caption; together they count as one unique feed/Reel unit. Stories do not count toward the 60.

Before searching, take the post ID and theme from the active slate (for example, `tue-02`). Do not invent a slot from whatever clip happens to be easy to find. Preserve the plan's audience/avatar and offer facts.

## 1. Find candidate source footage

In Google Photos on the phone:

1. Search by a useful date, class, or known scene; open candidate videos and scrub through them.
2. Look for a complete, understandable moment: coach cue or demonstration, learner attempt, visible adjustment/repeat, and a clean finish. A clip can be shorter than this sequence if it still proves its single point.
3. Check the frame for student names, faces, conversations, screens, or other people who did not agree to publication. For youth, confirm permission for this specific social use before selecting the clip. If unsure, skip it and use approved adult footage, coach-only footage, or hands/feet framing.
4. Note the original date and a recognizable source label. Do not alter or delete the original.

For YouTube footage, use only a video you own or have permission to reuse. Prefer the original camera file in Photos when available. A YouTube URL is a locator, not proof of reuse rights or a high-quality source. Avoid screen-recording a YouTube playback: it commonly reduces picture quality and can capture player controls, comments, or copyrighted audio. If the original file is unavailable, leave the post in draft until you have an authorized source file suitable for editing.

On the phone, make sure each chosen source is available to InShot as a local video. In Google Photos, use its save-to-device/download action when needed and confirm the file appears in the device gallery. For YouTube, use the original project/camera file or an authorized source file you control; do not use a playback recording as a substitute. If the source cannot be imported cleanly, pause here rather than building around a degraded copy.

Do not share private library links, student names, or identifying details in the ledger. Use a short source label such as `Photos / Sep 29 / adult grip demo` or a private YouTube video title kept on the user's device.

## 2. Match source to the brief

Before editing, fill this mini-brief:

```text
Post ID:
Avatar / audience:
Question the Reel answers:
Teaching point Sandy confirms:
Source label and original date:
Permission checked (especially youth): yes / no / not applicable
Opening moment (0–3 sec):
Proof moment to retain:
Ending frame:
Caption / CTA: Comment START for the link.
```

If the clip does not visibly support the teaching point, or needs a claim the footage cannot prove, choose another clip or ask Sandy to verify the wording. The avatar is a lens for relevance, not evidence about the person shown.

### Build a small source bin

When one recording does not contain the whole story, shortlist only the few moments needed for that post. Keep a note on the phone or in the brief; do not put student names or private share links in a shared tracker.

| Source | What it proves | Use in cut | Check |
|---|---|---|---|
| A: coach setup or cue | What to notice | Opening/context | Correct cue; permission |
| B: learner attempt | The skill in action | Main proof | Same drill and safe framing |
| C: adjustment or repeat | What changed | Payoff | Sandy confirms interpretation |
| D: room/coach end frame | Where to go next | Closing | No private details in frame |

Use only the rows the idea needs. A single strong clip is better than padding a Reel with unrelated footage. If clips come from different days, people, or drills, do not edit them to look like one continuous attempt. Use an honest visual/text transition such as “Another practice round” when that distinction matters.

## 3. Map the sequence before editing

Write a one-line cut map so you know what to keep before opening InShot:

```text
0–3 sec: Hook / clearest action
Next: Context or one coach cue
Next: Attempt that proves the point
Next: Adjustment or second view (only if it adds information)
Final: Clean end frame + next step
```

For a multi-clip synthesis, assign each source to a beat and order the clips to answer the brief's question. Prefer action-to-action cuts. Use a brief title card only when the source needs context; do not add a claim that the footage does not prove. Keep playback speed natural unless a brief slow view is needed to see a detail, then return to normal speed and label the edit if it could mislead.

## 4. Assemble in InShot

1. Start a new video and import the selected local source clip(s) in the order from the cut map. Keep the untouched camera originals in Photos.
2. Set a vertical 9:16 canvas for Reels. Reframe each shot so the teaching action stays visible in the center-safe area; check hands, feet, and faces after cropping. Recheck the crop after every shot change.
3. Trim each clip to its useful beat and arrange the timeline in story order. Put the clearest action or spoken hook first. Remove dead time, setup drift, repeated takes, and private conversation. Keep enough context that the movement remains honest and understandable.
4. Use clean cuts between related shots. Avoid flashy transitions that hide the action or imply continuity between separate takes. If shot scale changes, use the wide view for context and the close view for the detail; do not crop out a safety-relevant partner or movement.
5. Build one of these cuts:
   - **Short discovery cut: 16–30 seconds.** Hook/action, one cue, visible attempt or result, clean end.
   - **Longer lesson: 45–90 seconds.** Question, setup, explanation, demonstration, attempt, one adjustment, repeat, takeaway.
6. Add concise on-screen captions for spoken instruction. Keep text large, high-contrast, inside safe margins, and away from interface overlays. Review spelling and names. Do not make the video depend on sound alone.
7. Keep natural class audio only when clear and appropriate. If clips have very different sound, favor one clear voice track or original sound over jarring audio jumps. Use music only when its rights permit use on both Meta platforms; otherwise use original sound or no music. Do not add effects that change the apparent action.
8. Watch the full edit once with sound and once muted. Confirm the hook, sequence, and takeaway make sense in order; the clips do not falsely imply one continuous event; the movement is not obscured; the ending is intentional; and no unapproved person or private information appears.
9. Export a clean 1080 × 1920 vertical file if the source supports it. Save a post-specific copy; do not overwrite the original.

## 5. Caption and publish

Use the post's approved brief for the caption. Keep it factual, warm, and specific to what the clip shows. End with the canonical CTA: `Comment START for the link.` Use local tags only when relevant: `#catskills #bjj #tannersvilleny #hudsonvalley`. Do not use `@clockworkbjj` except on the week's single approved, genuinely relevant flagship technical post.

Post the same finished creative and caption to Facebook and Instagram feed/Reels. Do not substitute a Story for a feed/Reel slot. Confirm that the comment response path is being monitored before using the START CTA.

## 6. Log state and evidence

Record the post ID, source label, edit/export filename, and status. Statuses are `planned`, `drafted`, `scheduled`, `published-owner-reported`, or `verified-native`. Only a published feed/Reel with platform-native evidence earns ledger credit. For a cross-post, save both platform URLs or IDs on the same row and count the creative once. Record date/time and format; never treat a draft, schedule, screenshot of the editor, or Story as publication proof.

## Troubleshooting

- **Can't find a usable clip:** Search another date or class, use approved adult/coach-only footage, or capture a new sequence. Keep the post ID as draft until footage fits.
- **Clip is too short:** Build a short cut around one clear action; do not stretch it with slow motion or duplicate loops that misrepresent the class.
- **YouTube copy looks soft or has controls:** Do not screen-record around it. Find the original authorized file or request a suitable copy.
- **Youth permission is unclear:** Do not publish identifiable youth footage. Hold the edit and use an approved alternate.
- **Two Reels feel alike:** Change the learning question, teaching point, opening, proof scene, and caption. A new crop alone does not make a new unique creative.
- **InShot export or Meta upload fails:** Keep the source and local export, retry later, and leave the ledger at its current state until native post evidence exists.
