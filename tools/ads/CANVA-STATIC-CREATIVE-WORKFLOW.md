# Canva static creative workflow

This is the production workflow for every Ad Studio static and image/carousel
creative. The local generator may prepare post briefs, captions, and image
directions, but it does not produce the final graphic. Do not use local PNG
renders or ask the user to copy a Canva master for production.

## Production steps

1. Select the approved master by format:
   - [Single-image primary layout](https://www.canva.com/design/DAHWK0a7CJk/OYhxE6jggt9SWzXRaGGNVA/edit)
   - [Three-image alternative layout](https://www.canva.com/design/DAHWNnOl4UU/_YK9UTKromyId60yNF5C1g/edit)
2. Use the Canva integration to create a new copy for each planned post. Never
   edit a master or reuse one post's copy as another post's design.
3. Edit the copy's title and every post-specific on-image text field, including
   the headline, supporting/three-panel text, `Comment START for the link.`,
   and the address/offer footer. Use the complete current address from
   `src/_data/contact.json`. Check `src/_data/free-intro.json`, `offers.json`,
   and `pricing.json` before using free or paid offer language. Never put a
   `First Class FREE` footer on a visitor-only offer. For mixed paths, use a
   footer that distinguishes the free first visit from paid visitor options.
4. Keep the photo/image element editable and unchanged unless the user supplies
   or selects a specific approved image. The finished Canva copy should be
   ready for the user to replace its image(s), not require them to duplicate a
   master or rebuild text.
5. Preserve youth privacy and permission requirements. Use an anonymous or
   coach-only concept when permission for the specific Meta use is absent.
   Keep any technique, schedule, offer, or eligibility detail source-grounded.
6. Save the copy. The user has directed that separate commit approval is not
   needed for these requested Canva copies. Never save changes to the master.
7. Fetch the saved copy to verify its title and text, then return a direct Canva
   edit link grouped by post ID. State what image(s) the user should replace.
   A Canva asset being ready is not proof that it was published; native Meta
   URLs/IDs remain necessary for ledger credit.
