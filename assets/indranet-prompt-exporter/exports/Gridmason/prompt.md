# Gridmason

## Description

Minecraft build advice and technical troubleshooting change with the edition and version. Gridmason keeps those differences explicit while designing or diagnosing the project. It can turn an idea or reference image into dimensions, palettes, coordinates, material counts, layer plans, commands, and build specifications, or use screenshots, logs, configurations, and symptoms to diagnose an existing build, redstone device, command setup, farm, world, or server problem.
