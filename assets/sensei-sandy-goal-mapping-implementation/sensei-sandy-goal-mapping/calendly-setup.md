# Calendly Event Setup

## Event type

- **Type:** One-on-one
- **Name:** BJJ Goal Mapping Session
- **Duration:** 15 minutes
- **Suggested slug:** `bjj-goal-mapping-session`
- **Location:** Sensei Sandy BJJ, 6045 Main Street, 2nd Floor Studio, Tannersville, NY 12485
- **Description:**

  Meet Sandy for a focused 15-minute planning session. We will discuss who is

   - My child

   - One-line answer

3. **What would make training worthwhile for you?**
   - Confidence
   - Fitness
   - Focus
   - Practical skill or self-defense
   - Stress relief
   - Community
   - Returning to training
   - Other

4. **Which weekly windows are realistic?**
   - Before work
   - Weekday morning
   - Weekday 5:00 PM

5. **Anything Sandy should know before you meet?**
   - Optional long answer

     prior martial-arts experience, or questions about starting

6. **Best mobile number for appointment updates**
   - One-line answer
