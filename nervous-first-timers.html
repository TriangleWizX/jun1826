Your first semi-private class is a guided learning experience.

The Difference

Calm beginner-friendly martial arts means more than a soft slogan.

It means the first visit is organized, we teach grappling without striking, we welcome questions, and the coach gives you one clear next step instead of leaving you to decode the room alone.

If you are an adult beginner in the Catskills, start with the adult program. If you are choosing for a child, use the kids program. If you want one-on-one support first, see private lessons.

Questions

First-Timer FAQ

How is the first semi-private class paced for first-timers?

The first visit is built around a room tour, safety walkthrough, Beginner Lane orientation, and a clear next step.

What happens in my first Jiu-Jitsu semi-private class?

You meet Sandy, see the room, learn how tapping works, get paired carefully, and move through beginner-paced instruction before any intensity increases.

Do I have to spar hard on day one?

No. The first semi-private class is coached. Beginners start with safety, neutral work, chest-to-chest control, chest-to-back control, and standing engagement when skill level makes it appropriate.

What if I want a quieter first step?

Private lessons are available for beginners who want one-on-one coaching before or alongside Semi-Private Classes.
