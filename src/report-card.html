How to use the Report Card

How to read this card

This card shows what Sandy sees in training. It does not rank students. Look first at the current focus: what is working, what comes next, and what is starting to feel natural.

The notes come from coached practice in class. They do not measure a medical or school skill. See how class works or read the evidence ledger.

New to a BJJ word? Browse the beginner BJJ glossary for short, plain-language definitions.

Helpful terms: Base, Pin, Pin Escape, Guard, Guard Pass, Guard Retention, and Submission.

The Sensei Sandy BJJ Report Card is a quick way to review one student’s training. It shows what is improving, what is steady, and what problem to work on next.

It is made for calm, beginner-friendly Brazilian Jiu-Jitsu coaching in Tannersville, NY. Each area points to a skill we can see in class, such as staying safe, escaping a pin, passing guard, or finishing a hold.

  • Choose the state that best matches what the student shows in safe practice.
  • Add the date, coach, and class details.
  • Write what is working, what comes next, and what feels more natural.
  • Print or copy the card to share with the student and family.

Use the same state meanings each time. Update a state when the student shows a change in repeated training. No change is still information. Skills do not move only up. This keeps reviews useful for coaches, parents, kids, teens, and adults.
