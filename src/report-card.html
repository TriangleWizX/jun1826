Capability states
Not Yet Observed
There is not enough live evidence yet. This is not failure.
Emerging
The student can begin solving with prompting or favorable conditions.
Developing
Useful behavior is becoming consistent against appropriate resistance.
Contextual
The solution works in familiar or specific conditions and is still being tested across variations.
Reliable
The capability holds across meaningful variation and appropriate resistance; it is not perfection.

Progress is evidence, not a pass/fail result. Emerging → Developing means useful behavior is more consistent. Developing → Contextual means it is dependable in known conditions. Contextual → Reliable means it is surviving meaningful variation.

How To Use the Digital Twin Report Card

These observations come from the same coached positional problems used during regular classes. See how class works. Use the wider Parent Resources hub for safety answers, schedule planning, and other family-facing next steps that connect to this tracker.

The Sensei Sandy BJJ Digital Twin Report Card is a quick way to review training priorities and observable behavior for one student, one class lane, or one weekly coaching cycle. Coaches can update each capability state when recent drills, positional rounds, or live training provide enough evidence. The final output gives families and students a simple snapshot of what is improving, what is stable, and what problem should receive more attention next.

This report card format built for beginner-friendly Brazilian Jiu-Jitsu coaching in Tannersville, NY, where clear standards and calm communication matter. Instead of vague feedback, each category maps to observable habits like base retention, pin escapes, guard passing, and submissions. That structure helps reduce confusion for new students and gives returning students a predictable progression path.

  • Choose the capability state that best matches what the student currently demonstrates under appropriate resistance.
  • Record the current belt level, class schedule, and coach so each review is traceable.
  • Record what is working, the next problem, and what is beginning to become yours.
  • Print the final card for at-home practice goals and next-session accountability.

When comparing progress across weeks, keep the domain definitions and capability-state criteria consistent. Update a state when repeated training gives enough evidence that the student's behavior has changed. Consistency makes the report card useful for coaching decisions, parent updates, and long-term skill development across kids, teens, and adults.
