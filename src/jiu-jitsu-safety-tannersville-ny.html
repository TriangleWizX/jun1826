What happens first

  1. See the mat and learn where to sit.
  2. Learn the class rules and how to tap.
  3. Start with simple movement and coached practice.

Ask for help or a rest when you need one.

Class safety rules

  • When someone taps, let go at once.
  • Move with care and follow the coach.
  • Keep hands to yourself outside drills.
  • Use calm, respectful words.

Threats, bullying, or using a skill to scare someone can end class time.

Keep the mat clean

  • Wear clean training clothes.
  • Keep nails short.
  • Cover cuts.
  • Stay home when sick.
  • Wear shoes off the mat.

Tell Sandy if you need help with a class rule.

If someone needs a pause

We stop the drill and check in. A student can rest and reset. For youth classes, staff speak with the parent.

Parents can watch the class.
