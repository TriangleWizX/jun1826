How terms are chosen

We add words you may hear in class or see in a video. We start with safety words, key spots, and moves you may learn first.

This is a guide to class words. It is not a list of every BJJ move. It can help adults, kids, teens, and parents learn what a word means.

How to use the glossary before class

Pick two or three words to read. Then get set for class.

Start with base, posture, frame, and tap. Kids and teens can learn to reset, find their balance, stand up, and care for a partner.

FAQ

Quick answers about this page and the glossary.

Why does this page list changes?

So you can see what words we add or change.

Is this only for new students?

No. Students and parents can use it to learn class words.

How often is this page updated?

When we change a term and build the site. The counts use the same data as the glossary.

What if a class word is missing?

Read a close term, then ask your coach what the word means. We may add words that students ask about often.
