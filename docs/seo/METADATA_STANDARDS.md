# Metadata Standards — SenseiSandy.com

## Meta Title Standards
- Must be unique per indexable page.
- Format: `[Page Topic/Title] | Sensei Sandy BJJ [Location optional]`
- Length: 50–60 characters.
- Single H1 per page aligned with title intent.

## Meta Description Standards
- Must accurately summarize visible page content.
- Length: 120–155 characters.
- Must include clear value proposition or local context without keyword stuffing.

## Open Graph & Social Cards
- `og:title`, `og:description`, `og:url`, `og:type` (`website` or `article`), `og:image`
- `twitter:card` (`summary_large_image`)
