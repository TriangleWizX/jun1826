## Executive Summary & Strategic Rationale

Following the successful transformation of Alley Bootcamp (incorporating the Hormozi Value Equation, visual trust seals, interactive selectors, tiered pricing, and sticky mobile CTAs), the academy's three core program landing routes—**Adult BJJ**, **Kids BJJ**, and **Teens BJJ**—have been audited to identify parallel conversion enhancements.

While each audience has distinct psychological triggers and buyer avatars, all three benefit directly from Hormozi's **Grand Slam Offer Architecture**:
1. **Visual Risk Reversal**: Elevating the official **30-Day Training Fit Guarantee** from a small footer link into a high-status graphic trust emblem.
2. **Speed to First Win (14-Day Timeline)**: Pre-framing the first two weeks of class so beginners and parents visualize undeniable momentum immediately.
3. **The Complete Value Stack**: Explicitly bundling high-value deliverables (First-Enrollment Uniform & Belt, Async Video Practice Vault, Class Capping at 12 students, Text Rescheduling) into the core offer.
4. **Frictionless Mobile Conversion**: Introducing sticky mobile action bars with thumb-friendly tap targets and pre-filled text triggers.
5. **Positive Beginner Framing & 3rd-Grade Reading Level**: Ensuring all copy is 100% affirming with zero negative or intimidating language.
